# 角色 05：政見發表者（原型人物）

以台北市長政見發表會畫面中的「原型人物」為靈感，Q 版程序化 GLB（`tools/build-character-05.mjs`，`npm run build:character-05`）。參考畫面只用於目視，不提交、已刪除；repo 內不寫姓名。

- 外型：年長男性、較大的長圓臉（頭部比其他角色大）、深棕往後梳的頭髮並帶灰鬢、無眼鏡、特別粗的濃眉、半瞇眼、厚嘴唇（閉嘴）。
- 服裝：深炭灰西裝外套、深色背心、白襯衫、棕色條紋領帶、深色長褲與黑皮鞋。
- 道具：左手握紅底宣傳板（黃、綠色塊，僅為色塊、無可讀文字）。
- 已知限制：頭髮為單一髮罩，偏圓；臉部紋路僅以凹陷表現；板面無文字；未在實戰場景驗證。
- 01–05 的手同 06 規範：左右鏡像、四指較細且間距加大、指起點移入掌內。
