# 角色 07：新北市長候選人（原型人物）

以選舉期間公開新聞照片中的「原型人物」為靈感，Q 版程序化 GLB（`tools/build-character-07.mjs`，`npm run build:character-07`）。參考照片只用於目視、不提交（`assets/characters/references/` 已列入本機排除），repo 內不寫姓名。

- 外型：下巴長度的黑色短鮑伯，整片瀏海連到頭頂髮片（無露頭皮的縫）；細金框圓眼鏡；圓潤臉型；淺笑閉嘴、粉紅唇色。
- 服裝：粉色西裝外套（開襟、翻領）、白色針織上衣、黑色長褲、白色運動鞋；外套左胸小金色別針。
- 手部：沿用 01–06 的鏡像握拳規範。
- 已知限制：瀏海為直切、未做側分斜掃；眼鏡為單純圓框；未在實戰場景驗證；招式特效仍是原本的修女版本，尚未配合新造型調整。
