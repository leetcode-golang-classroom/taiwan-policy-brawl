# 角色 08 新北市長候選人（原型人物）造型記錄

參考：選舉期間新聞照片（僅目視參考，不入版控）。以描述性文字記錄：

- 髮型：灰黑色短髮，向後梳，髮際線偏高，額頭外露；鬢角短。
- 臉：蛋形偏方的下巴、較粗的眉毛、黑色方框眼鏡、淺笑閉嘴（無口紅）。
- 服裝：天藍色競選背心（黑色拉鍊與黑色滾邊、左胸名牌）、淺藍色襯衫長袖、黑色長褲、白色運動鞋。
- 手：沿用 01–07 的左右鏡像放鬆握拳。
- 生成：`npm run build:character-08`，輸出 `public/assets/characters/character-08/fighter.glb`（由 07 的腳本改寫）。

限制：背心為單色，黑色滾邊以平條表示；眼鏡為細條拼成的方框；技能特效仍是舊的工程主題。
