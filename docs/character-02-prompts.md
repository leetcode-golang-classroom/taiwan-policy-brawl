# 角色 02 模型與普通攻擊說明

- 造型：圓框細金屬眼鏡、濃密黑色捲髮、淺笑，穿深炭灰色西裝（白襯衫、酒紅領帶、翻領、口袋巾）、西裝褲、黑皮鞋。Q 版比例與 01 相同。
- 生成：`npm run build:character-02`（`tools/build-character-02.mjs`，由 01 的生成器衍生，同樣的骨架與 21 個動作）。
- 參考人物以「原型人物」稱呼，repo 內不放真人姓名與照片。
- 普通攻擊「都市縫合」：範圍型攻擊（range 6）。兩排都市土牆從對手左右合攏夾擊，接縫處出現縫線針腳。
  - 動作：雙臂張開後合掌（GLB 的 `Punch` 動作與占位角色的 `animation.js` 都已改）。
  - 特效：`src/skills/leopard.js`（出招）、`src/presentation/vfxEvents.js`（命中塵土與縫線環）。
  - 數值沿用原本撲擊的擊退／擊飛／硬直（knockback 1.55、launch 4.4、stun .58），只改為範圍型。
- 01–05 的手同 06 規範：左右鏡像、四指較細且間距加大、指起點移入掌內。
