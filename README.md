# 台灣大亂鬥 V3.9 — Three.js 3D 格鬥

以虛構政策流派角色為主題的 3D Arena 格鬥原型。角色全部以 Three.js 基礎幾何體即時組合，不需要外部模型或貼圖。
本作品為虛構遊戲，角色、外觀與招式均為創意設定。

## 環境與啟動

需要 Node.js 20.19+ 或 22.12+，以及 pnpm。

```bash
pnpm install
pnpm dev          # 開發模式，http://localhost:5173
pnpm run build    # 正式建置到 dist/
pnpm preview      # 預覽建置結果
pnpm test         # 單元測試（Entity 與 Control，95 項）
```

網址加上 `?debug` 會把 ECS world 掛到 `window.__PB`，僅供測試使用。

## 操作

| 按鍵 | 功能 |
|---|---|
| `W A S D` | 移動（相對鏡頭；八方向，雙擊方向鍵為衝刺） |
| `J` | 普通攻擊（三段連段） |
| `K` | 蓄力特殊技 |
| `L` | 蓄力大招（能量 100% 才能用） |
| `I` | 專屬防禦：持續 1.5 秒，冷卻 6 秒，減傷 70%，可擋可被阻擋的飛行道具 |
| `Space` / `Shift` | 跳躍 / 角色專屬閃避（閃避中短暫無敵） |
| 滑鼠拖曳 | 旋轉視角 |

## V3.9 修改摘要

**架構**：從單一 810 行 `main.js` 改為 ECS。
- `ecs/`：`World`、純資料 Components、Entities。
- `systems/`：純邏輯 System，不 import three 或 DOM。
- **Control 系統**：`playerControl`（鍵盤）與 `aiControl`（CPU）只負責寫入 `Intent`，其他 System 再消費 Intent。
- `presentation/`、`ui/`、`vfx/`：只讀 Components、訂閱 `world.events`，不改遊戲狀態。

**戰鬥**
- P1 與 CPU 是對稱的 Entity。
- `resolveHit()` 是唯一的扣血入口，依序處理閃避、防禦、扣血、擊退、能量與事件。
- 技能資料表（`config.js`）有 `type / damage / range / speed / cooldown / radius / knockback / tracking / blockable`。
- 近戰有距離限制；飛行道具有速度、飛行時間、球體碰撞、命中即消失與追蹤；範圍與衝刺攻擊也走同一套判定。

**回饋**
- 兩位角色的生命與能量條疊在競技場上方，不必捲動。
- 傷害數字取自實際扣血量，並依大小分級；另有連擊計數、受擊閃光、大招鏡頭震動。

**動作**
- 攻擊分六階段：準備、蓄力、出手、命中、收招、待機。
- 移動有前後左右與斜向，走路動作依角色不同。
- 受擊反向傾斜、擊退距離隨傷害增加、強招擊飛並有落地反應。
- 九位角色的武器或道具各自旋轉、發光，蓄力時越轉越快、越亮。

**I 鍵專屬防禦**：九位角色各有專屬畫面，CPU 也會使用。
- 01 旋轉徽章護盾
- 02 芒果乾屏障
- 03 旋轉麻將牆
- 04 魔法結界
- 05 聖光環
- 06 金色肌肉護盾
- 07 工程鋼板
- 08 工程防護牆
- 09 多層泡泡（每次受擊破一層）

**角色改版**
- 01：藍色洛克人風裝甲與手臂砲，胸前為金色佛教卍。
- 02：豹型守護者，三招都有貓科動作：J 豹之撲擊（衝刺型攻擊，命中時被擊中處長出一片樹林，CPU 也會從遠處撲）、K 低身雙爪連抓並帶爪痕、L 後腿站起再撲地並放出震波。
- 03：海軍上將裝束（白色制服、金肩章與鈕釦、勳表、軍帽加錨徽），武器改為旋轉發光的「麻將尺」。
- 04：魔法師。
- 08：大禹文官形象（冕旒冠、青綠朝服與紅腰帶、玉笏、治水鍤，無光環）；L 改為「百川匯海」：八條河流從四面衝向對手，水柱升起把對手淹沒（範圍型，判定沿用原本大招）。
- 06：J 改為「重拳出擊」：角色左右交替揮拳，五個紅色拳擊手套成扇形飛向對手（飛行道具判定，速度 10、射程 6.5）。
- 07：光明使者（原都更拆遷王），白衣修女造型（白修士服與白頭巾、淺藍飾邊、金十字與法杖，無光環；身體與四肢也改為白色）；J 改為「乾坤大挪移」：大量銀行鈔票飛出並蓋住對手（判定沿用原本的飛行道具）；L 改為「神之震怒」：巨大光之拳從天而降敲擊對手，對手被打得往後飛（範圍型，擊退 6、擊飛 6.5）。
- 06：第二招改名「風花雪月」：一群阿姨從豆干厝窄巷衝出，把對手拉進小巷（判定仍是原本的衝刺型攻擊）。
- 07：第二招完全換成**電光火球**（傷害 10、射程 15、速度 12、半徑 1.2、擊退 5、冷卻 5 秒，可被 I 防禦擋下）。

## 專案結構

```text
src/
├── main.js            # 組裝 World、場景與遊戲迴圈
├── config.js          # 防禦、冷卻、技能資料表
├── roster.js          # 九位角色資料
├── ecs/               # World、Components、Entities
├── systems/           # status/playerControl/aiControl/defense/action/movement/projectile/physics/round
├── input/             # 鍵盤與滑鼠
├── presentation/      # 動畫、渲染同步、特效事件、防禦畫面
├── characters/        # 九位角色造型
├── skills/            # 各角色技能視覺
├── vfx/  ui/          # 粒子與 HUD、傷害數字、訊息
tests/
├── entity/            # World / Entity 測試
└── control/           # 玩家、AI、戰鬥、防禦、移動、電光火球
```

## 驗收結果（spec §十一，共 17 項）

驗證方式：「自動測試」是 `pnpm test`（只測 Entity 與 Control）；「瀏覽器」是 headless Chrome（軟體渲染）跑 `pnpm preview` 的煙霧測試與截圖。**畫面與動畫品質沒有在真實 GPU 與正常幀率下看過，需要人工確認。**

| # | 項目 | 結果 | 依據 |
|---|---|---|---|
| 1 | P1 與 CPU 生命值顯示 | 通過 | 瀏覽器截圖可見兩邊血條與數字；自動測試確認對稱 Entity 與滿血出生 |
| 2 | 命中出現傷害數字 | 通過 | 瀏覽器煙霧測試中畫面上有傷害數字元素 |
| 3 | 數字與實際扣血一致 | 通過 | 數字取自 `hit` 事件的實際扣血量；有扣血與 HP 範圍測試 |
| 4 | 近戰有距離限制 | 通過 | 自動測試：每個技能在範圍內命中、範圍外落空（電光火球因射程 15 大於場地寬 14，無法測範圍外，已跳過） |
| 5 | 投射物飛行與命中 | 通過 | 自動測試：有飛行時間、命中後消失、追蹤、閃避穿過 |

| 7 | 九角色都能 I 防禦 | 通過 | 自動測試涵蓋防禦邏輯；各角色防禦截圖僅看過 02、08、09（`/tmp` 內截圖，未納入專案）|

| 11 | 蓄力、出招、收招 | 邏輯通過、動畫未驗 | 自動測試確認六階段順序與時間；姿勢外觀同上 |

## 尚未完成或有限制

以下都沒有宣稱完成：

1. **02 豹的貓科動作只在軟體渲染下看過截圖**：J 豹之撲擊（躍起衝刺）、K 工人隊（低身雙爪連抓）、L 大海（後腿站起吼叫後撲地）、蓄力時壓低身體顫抖。三招的實際效果（飛出的工人、大海浪）仍是原本的視覺，只有豹本身的姿勢與爪痕、震波是新做的，請實機確認動作流暢度。
2. **風花雪月只換了視覺**：阿姨群與巷弄是特效，判定仍是 06 原本的衝刺攻擊，對手並不會真的被拉進巷子。我把「豆乾厝」理解為窄長的老式連棟房屋，若你指的是別的意象請告訴我。
3. **擊退是瞬間位移**：電光火球的 5 單位擊退會直接瞬移，看起來突兀。
4. **沒有通用的前衝動作**：近戰角色出招時不會統一往前踏步。
5. **防禦是全向的**：不看攻擊來向，只有通用的受擊波紋。
6. **武器旋轉與發光只套在各角色選定的一件道具上**，其他裝飾不會轉。
7. **所有動作與特效都沒在正常幀率下看過**：測試環境是軟體渲染，約 3 幀每秒；姿勢、走路、電弧的實際觀感需人工驗證。
8. **01 的卍朝向**沒在近距離確認過；原本的領帶與翻領有一部分被胸甲遮住。
9. **電光火球射程 15 大於場地寬 14**：在場內沒有「射程外打不到」的情況。
10. **沒有自動化的 UI 與畫面測試**：依專案約定，測試只涵蓋 Entity 與 Control。
11. **沒有音效、連線對戰或骨架模型。**
